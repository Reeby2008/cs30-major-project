# What I'm Proud of
- I'm most proud of the organization of my code and thankful that I integrated HTML for the visual aspect. I believe my code is well organized, well commented, efficient and overall readable. Having HTML for the buttons reduces a lot more code and overall made my life easier because I was able to shorten my code and it made sure that the buttons didn't keep on breaking on me.

# Most Challenging Part
- The most challenging part of this project was creating the buttons through HTML. I mainly chose to use HTML because it is visually more flexible. If you would like to minimize your screen the elements will automatically adjust without you having to hit the refresh button. I had a hard time with this because I couldn't get the button to disappear when it is clicked through sketch.js. I realized later on it was because I put a class on the button instead of an id. Overall, switching it all over was a messy process.
